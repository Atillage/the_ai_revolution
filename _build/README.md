# How this site is built

The pages on theairevolution.net are generated by `build.py`. Edit `build.py`, not the HTML pages directly; most pages are rebuilt from it and hand edits to them will be overwritten.

## Rebuild the site

From the top folder of this repository:

```
python3 _build/build.py .
```

That regenerates the pages, updates the menu and footer on every page, and adds version tags to scripts and stylesheets so visitors' browsers load the newest code.

## Things kept outside build.py

- Article list on Understanding AI: edit `ARTICLES` in `learn.js`.
- Styles: `ecosystem.css` (newer) and `style.css` (original).
- Interactive tools: the `.js` files in the top folder.

## Parked ideas

`parked/` holds drafts that are not on the site yet (for example the homeschool guide).

Folders that start with an underscore are not published on the website.
