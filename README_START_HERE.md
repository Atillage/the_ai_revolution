## Replace the files on GitHub

1. Back up the existing repository with Code → Download ZIP.
2. Use the same publishing branch and folder as your current website. Settings → Pages shows the branch/folder for branch publishing. For GitHub Actions or another host, use the website folder its current workflow publishes.
3. Choose Add file → Upload files inside that folder. Drag in the CONTENTS of AI-Revolution-Website, including blog/ and images/. Do not upload the ZIP or an extra enclosing folder. index.html and understanding-ai.html must sit together.
4. Matching paths replace the old versions. Preserve CNAME, .github, .nojekyll and your existing hosting configuration.
5. Review the files, enter “Combine Blog and LAB into Understanding AI,” then Commit changes. If a pull request is required, merge it to your publishing branch after review.
6. Wait for your host to finish publishing, then check the menu, Guides, the combined page, a website article, a Substack article and a Gumroad product. Try search and filters. Old /lab.html and /blog/ addresses should forward to the combined page.

GitHub upload reference: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
